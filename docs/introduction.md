# shantytown

**A small harness for running a crew of coding agents.** Create a work item. Tell an agent to go
get it. That's the whole idea — and this book is everything the [README](https://github.com/scbrown/shantytown#readme)
deliberately leaves out.

Start with [Why Shantytown?](why.md) if you want to know what it is not, [Getting started](getting-started.md)
if you want a town in five questions, and [The CLI](cli.md) when you want every command and every
exit code. The design chapters explain the shape; the reference chapters explain the knobs.
